# VIDO Social — Landing Design Assets

## Käyttöperiaate

Kaikki `assets/landing/`-hakemiston visuaalit ovat kuvitteellisia demoja. Niitä käytetään palvelun, sisältötyyppien, raportoinnin ja verkkosivun mahdollisen ulkoasun havainnollistamiseen.

Niitä ei saa esittää:

- oikeina asiakascaseina
- oikeina tuloksina tai suorituskykylukuina
- asiakkaiden hyväksyminä referensseinä
- todellisina arvosteluina tai käyttäjämäärinä

## Landing-sivulla käytettävät SVG-assetit

- `assets/landing/demo-social-posts.svg` — kuvitteelliset mallijulkaisut

- `assets/landing/growth-dashboard.svg` — VIDO Kasvun demodata-dashboard

## Brändisuunta

- tausta: syvä navy / lähes musta
- korostus: VIDO-punainen
- teksti: valkoinen ja lämmin vaalea
- kortit: hienovaraiset rajat, lasimaiset pinnat ja hillityt hehkut
- typografia: vahva geometrinen sans-serif / järjestelmäfontti
- kuvien yhteydessä aina näkyvä `Demo`, `Mallijulkaisu`, `Demodata` tai `Kuvitteellinen esimerkki` -merkintä

## Landing-sivun toteutusperiaate

1. Hero näyttää palvelun arvon ja yhden selvästi merkityn demovisuaalin.
2. Mallijulkaisuosio konkretisoi sisällön mahdollisen ulkoasun ilman asiakasväitteitä.
3. Prosessigrafiikka havainnollistaa materiaalit → suunnittelu → tuotanto → hyväksyntä → julkaisu -ketjun.
4. Raportointigrafiikka käyttää vain demodataa.
5. Verkkosivumockup on kuvitteellinen mallisivu, ei referenssi.
6. Palvelupakettien hinnat ja sisällöt noudattavat lukittua tuotteistusta.
